SEERAK WEBSITE - GITHUB PAGES

FILES
- index.html: website content
- style.css: layout, colours and responsive design
- images/: replaceable image files named image 1.jpg, image 2.jpg, etc.

HOW TO REPLACE AN IMAGE
1. Open the images folder.
2. Replace the required image file with your own photo.
3. Keep the exact same filename (for example: image 1.jpg) and JPG format.
4. Refresh the website.

GITHUB PAGES
1. Extract this ZIP.
2. Upload index.html, style.css and the images folder to your GitHub repository root.
3. Commit the changes.
4. In GitHub, open Settings > Pages.
5. Select Deploy from a branch, choose main and /(root), then Save.
